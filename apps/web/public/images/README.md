# Login artwork

`login-spacewalk.jpg`: NASA photograph of Bruce McCandless II during the first untethered spacewalk (STS-41B, February 7, 1984). Credit: NASA.

Source: https://www.nasa.gov/image-article/astronaut-bruce-mccandless-performs-the-first-untethered-spacewalk/
Original image: https://www.nasa.gov/wp-content/uploads/2024/02/s84-27018orig.jpg

The original photograph is served locally with Next.js image optimization. Text and feature icons are HTML/SVG overlays, not embedded in the photograph.

Source: https://www.nasa.gov/image-article/earthrise-by-nasa-astronaut-bill-anders/
Original image: https://www.nasa.gov/wp-content/uploads/2024/06/as08-14-2383orig.jpg
